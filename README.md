# 🏁 수학 레이싱 (Math Kart Race)

학생 30명 내외가 교사 QR 코드로 한 방에 입장해, 화면 상단 문제의 **정답 코스로 게이트를 통과하면 부스트**를 얻는 레이싱 수학 퀴즈 웹앱입니다.
코스 테마: 🛷 설원 눈썰매 · 🏄 폭포 서핑 · 🚴 고속도로 자전거 · 🎲 학생이 직접 고르기

- 설치·빌드 없이 그대로 동작합니다 (순수 HTML + JavaScript 모듈, Node.js만 있으면 로컬 실행 가능).
- 수식은 KaTeX로 표시합니다 (`$x^2$`). 라이브러리는 `public/vendor/` 안에 들어 있어 인터넷 없이도 수식이 보입니다.
- QR 코드도 자체 생성합니다 (외부 서비스 없이 동작).

---

## 1. 먼저 혼자 테스트하기 (5분)

```bash
cd kart-math-race
node tools/serve.mjs
```

1. 브라우저에서 `http://localhost:5173/teacher.html` → 교사 콘솔이 열리고 방 번호와 QR이 생깁니다.
2. QR 아래의 주소를 클릭하면 **같은 브라우저의 새 탭**에서 학생 화면이 열립니다. 탭을 여러 개 열면 학생 여러 명처럼 테스트할 수 있어요.
3. 교사 콘솔에서 **🏁 레이스 시작!**

> 화면 아래에 "로컬 테스트 모드"라고 뜨는 동안에는 같은 브라우저의 탭끼리만 연결됩니다.
> 실제 수업(학생 태블릿·크롬북)에서 쓰려면 아래 2번의 Firebase 설정을 해 주세요.

## 2. 실제 수업용으로 올리기 (Firebase 무료 Spark 요금제)

1. https://console.firebase.google.com → **프로젝트 추가**
2. 왼쪽 메뉴 **Authentication → 로그인 방법 → 익명** 사용 설정 (꺼져 있으면 화면에 빨간 안내가 뜹니다)
3. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기** (위치: `asia-southeast1` 권장, "잠금 모드"로 시작해도 됩니다 — 규칙은 배포 때 자동 적용)
4. **프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹 앱(</>) 추가** → 나오는 `firebaseConfig` 값을
   `public/js/firebase-config.js` 에 붙여넣기 (`databaseURL` 꼭 포함)
5. 터미널에서:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase use --add        # 방금 만든 프로젝트 선택
   firebase deploy
   ```
6. 배포가 끝나면 나오는 주소(`https://프로젝트이름.web.app/teacher.html`)를 전자칠판에서 열면 끝!

> 30명 동시 접속은 무료 요금제 한도(동시 연결 100개) 안에서 충분합니다.

## 2-B. 깃허브(GitHub Pages)에 올리기 — 명령어 없이

깃허브는 웹사이트(화면)를, Firebase는 학생들 실시간 연결(Realtime Database)만 맡습니다. 둘 다 무료예요.

**① Firebase 준비 (실시간 연결용)**
1. https://console.firebase.google.com → 프로젝트 만들기 (Google 애널리틱스는 꺼도 됨)
2. Realtime Database → 데이터베이스 만들기 → 위치 `싱가포르(asia-southeast1)` → 잠금 모드로 시작
3. Realtime Database의 **규칙** 탭 → 내용을 모두 지우고 `database.rules.json` 파일 내용을 붙여넣기 → **게시**
4. **Authentication → 시작하기 → 로그인 방법(Sign-in method) → 익명 → 사용 설정 → 저장** (학생은 계정 없이 자동으로 익명 로그인되고, 규칙이 로그인된 접속만 허용합니다)
5. 프로젝트 개요 옆 ⚙️ → 프로젝트 설정 → 내 앱 → 웹(`</>`) 앱 등록 → 나온 `firebaseConfig` 값을 `public/js/firebase-config.js`에 붙여넣기 (`databaseURL` 포함)

**② 깃허브에 올리기 (GitHub Desktop 사용)**
1. https://github.com 가입 → https://desktop.github.com 에서 GitHub Desktop 설치 후 로그인
2. File → Add local repository → `kart-math-race` 폴더 선택 → "create a repository" → Create repository
3. 오른쪽 위 **Publish repository** → "Keep this code private" **체크 해제** → Publish
4. 웹에서 저장소 열기 → **Settings → Pages → Source: GitHub Actions**
5. **Actions** 탭 → "Deploy to GitHub Pages" → Run workflow (초록 체크가 뜨면 완료, 1~2분)
6. 주소: `https://깃허브아이디.github.io/kart-math-race/teacher.html`

**문제를 바꿀 때:** `questions/` 폴더에 파일을 넣고 → GitHub Desktop에서 Summary 적기 → Commit to main → Push origin → 1~2분 뒤 자동 반영.

> 공개 저장소이므로 문제·정답 파일도 누구나 볼 수 있습니다(웹사이트로 서비스되는 문제 파일은 어차피 브라우저로 받아지므로 완전히 숨길 수는 없어요).
> 깃허브가 "API key가 공개됐다"는 경고 메일을 보낼 수 있는데, Firebase 웹 설정값은 원래 공개되는 값이라 괜찮습니다. 보안은 3번의 규칙이 지켜 줍니다.

## 3. 문제 넣기 — `questions/` 폴더

파일 하나 = 문제 세트 하나. 파일 이름 앞 번호(`01_`)는 정렬용이고 나머지가 세트 제목이 됩니다.
자세한 형식은 `questions/_사용법.txt`, 엑셀 양식은 `questions/_양식.csv` 를 보세요. (`_`로 시작하는 파일은 게임에 나오지 않음)

**엑셀(CSV)** — 열 순서: `문제 | 정답 | 오답1 | 오답2 | 오답3 | 오답4 | 오답5 | 제한시간(사용 안 함) | 해설(선택) | 그림(선택)`

**그림이 있는 문제** — 그림 파일을 `questions/images/`에 넣고 '그림' 칸에 파일 이름을 쓰면, 학생 화면 문제 칸 옆에 그림이 나오고 누르면 크게 보입니다.
엑셀에서 "CSV(쉼표로 분리)"로 저장한 한글 파일(EUC-KR)도 자동 인식합니다.

**메모장(TXT)**
```
# 연립방정식
Q: $x+y=5,\; x-y=1$ 의 해에서 $x$의 값은?
A: 3
X: 2
X: 4
T: 15
E: 두 식을 더하면 2x=6
```

- 오답은 1~5개 → 정답 포함 2~6개의 코스가 생기고, 코스 위치는 매번 섞입니다. (교사 콘솔 '선택지(코스) 수'로 최대 개수를 줄일 수 있어요)
- **반영 방법**
  - 로컬 서버 사용 중: 교사 콘솔의 **🔄 문제 폴더 다시 읽기** 만 누르면 바로 반영
  - Firebase: `firebase deploy` 할 때 자동으로 묶여서 올라감
  - 급할 때: 교사 콘솔의 **📂 파일 직접 불러오기** (배포 없이 바로 사용)

## 4. 수업 진행 흐름

| 단계 | 교사 콘솔 (전자칠판) | 학생 화면 |
|---|---|---|
| 입장 | QR·방 번호 표시, 입장한 캐릭터가 하나씩 등장 (× 버튼으로 퇴장) | 이름·헬멧 색·장식 고르고 입장 |
| 설정 | 테마, 문제 세트, 문제 수, 기본 시간, 순서 섞기 | 대기실에서 조작법 확인 |
| 레이스 | 문제·남은 시간, 실시간 순위 트랙, 게이트 통과 후 응답 분포·정답률, ⏸ 일시정지 / ⏭ 다음으로 / 🏁 종료 | 상단 문제 → ◀▶ 또는 정답 칸 터치로 코스 이동 → 게이트 통과 시 판정 |
| 결과 | 시상대, 전체 순위표, 문제별 정답률 | 내 순위·정답 수·최고 연속·달린 거리 |

**코스·아이템 (v2)**
- 한 바퀴 1.6km 순환 서킷(LAP 표시, 오른쪽 위 서킷 미니맵). 커브, **점프대**(만세 하며 날아오름), **파란 화살표 가속 발판**(한 코스에만 놓임, 잠깐 부스트)
- 두 갈래 길 2곳: **🌉 고가도로**(오른쪽 길이 위로 올라갔다 내려옴), **🚇 지하터널**(왼쪽 길이 터널로 들어감). 두 길이 완전히 갈라진 동안에는 반대쪽 길로 넘어갈 수 없어요. 이때 정답 칸을 고르는 것은 그대로 되고(판정은 고른 답 기준), 캐릭터만 길이 합쳐진 뒤에 그 코스로 이동합니다.
- 다른 레이서와 부딪히면 "쿵!" 하고 잠깐 감속 (뒤에서 들이받거나 옆으로 끼어들 때)
- **아이템전**(교사 설정에서 끄면 스피드전): 코스의 `?` 상자를 지나가면 아이템 획득(최대 2개), SPACE 키 또는 아이템 칸 터치로 사용, X 키 또는 🗑️ 버리기 버튼으로 버리기
- 누군가 상자를 먹으면 그 자리 상자는 4초 뒤에 다시 생겨요 (모든 학생 화면에서 함께)
  | 아이템 | 효과 |
  |---|---|
  | 🍌 바나나 | 내 뒤에 설치. 밟은 레이서는 3바퀴 빙글 돈 뒤 멈춤 |
  | 🚀 미사일 | 바로 앞 레이서에게 발사 → 경보 후 명중, 공중 2바퀴 뒤 멈춤 |
  | 🌫️ 안개 | 내 뒤 레이서들 화면이 5초간 뿌옇게 (문제 칸은 가리지 않음) |
  | 💨 니트로 | 2초 초고속 |
  | 🛡️ 방패 | 6초간 공격·충돌을 한 번 막음 |
  | 💧 물폭탄 | 앞쪽 45m 안 레이서들을 물방울에 가둠 |
- 아이템은 순위에 따라 확률이 달라요: 앞쪽은 바나나·방패·안개, 뒤쪽은 미사일·니트로·물폭탄이 잘 나와 역전 기회가 생깁니다.
- 교사 콘솔 오른쪽에 서킷 미니맵과 실시간 아이템 기록(🚀 민준 → 서연 등)이 표시됩니다.

**레이스 방식 (v5)** — 한 바퀴(1.6km, 최고 속도로 약 55초) = 한 문제
- 각 학생은 자기 속도로 달리며, 바퀴마다 한 곳 있는 **문제통과지점**을 지날 때 그 순간의 코스로 판정됩니다. 판정 직후 정답·해설이 3초 보이고 바로 다음 문제가 나와요.
- 문제 수만큼 바퀴를 돌고 **결승선을 먼저 통과한 순서**가 순위입니다. 모두 완주하면 레이스가 자동으로 끝나요.
- 한 바퀴 배치: 출발 → 아이템 상자 → 🌉 고가도로 갈림길 → 가속발판 → 점프대(만세!) → 🚇 지하터널 갈림길 → 문제통과지점 → 결승선 (서로 150m 이상 떨어져 있어요)
- 코스 너비는 선택지 수만큼(최대 6코스). 아이템 상자는 모든 코스에, 가속발판은 한 칸 걸러 놓이고 바퀴마다 짝·홀 코스가 번갈아 바뀌어요.
- **가속 조작**: ▲ 가속 버튼(태블릿) 또는 ↑ 키를 누르고 있으면 약 2초에 걸쳐 최고 속도까지 오르고, 떼면 천천히 느려집니다(↓ 키는 브레이크). 그래서 학생마다 속도가 달라요. 정답 부스트·발판·니트로 중에는 손을 떼도 최고 속도로 달려요.
- 교사 화면: 문제 칩(Q1, Q2…)마다 통과 인원·정답률이 실시간으로 보이고, 기본은 '가장 많은 학생이 풀고 있는 문제'를 보여 줍니다. 정답은 모두 통과하거나 '정답 공개'를 누를 때만 표시돼요.

**게임 규칙** — 각자 가속 버튼으로 속도를 조절하며 달리고, 정답 코스로 통과하면 부스트(연속 정답일수록 길게), 오답이면 잠깐 감속합니다.
순위의 중심은 정답 수와 연속 정답이고(부스트가 가장 큼), 아이템·발판·충돌이 재미 요소로 더해집니다. 순수 실력으로만 겨루려면 '아이템전'을 끄세요.

- 학생이 새로고침하거나 와이파이가 끊겼다 들어와도 같은 기기면 이어서 달립니다.
- 늦게 들어온 학생은 꼴찌 위치에서 출발하고, 못 본 문제는 판정하지 않습니다.

## 5. 조정하고 싶을 때

`public/js/common.js` 맨 위 `GAME` 값:
`BOOST_MULT`(부스트 세기), `BOOST_TIME`, `STREAK_BONUS`(연속 정답 보너스), `SLOW_MULT`(오답 감속), `RESULT_TIME`(정답 공개 시간), `DEFAULT_Q_TIME`, 아이템·충돌 세기(`SPIN_TIME`, `FLY_TIME`, `FOG_TIME`, `BUMP_MULT` 등)

코스 모양(커브·갈래길·점프대·발판·상자 위치)은 `public/js/track.js` 에서 바꿀 수 있어요.

## 폴더 구조

```
kart-math-race/
├─ questions/              ← 여기에 문제 파일을 넣으세요
├─ public/
│  ├─ teacher.html         교사 콘솔
│  ├─ play.html            학생 화면
│  ├─ js/
│  │  ├─ firebase-config.js   ← Firebase 설정 붙여넣는 곳
│  │  ├─ race-renderer.js     3D 레이스 화면(테마별 배경·코스·이펙트)
│  │  ├─ rider.js             캐릭터+탈것 뒷모습(썰매·서핑·자전거)
│  │  ├─ track.js             순환 코스 정의
│  │  ├─ student.js / teacher.js
│  │  ├─ question-parser.js   CSV/TXT/JSON 문제 읽기
│  │  ├─ backend.js           Firebase / 로컬 테스트 모드
│  │  └─ qr.js                QR 코드 생성
│  └─ data/question-sets.json (자동 생성)
├─ tools/serve.mjs         로컬 서버
├─ tools/build-questions.mjs
├─ firebase.json / database.rules.json
```

> 보안 참고: 학생 로그인이 없는 수업용 구조라 방 번호(6자리)를 아는 사람은 방 데이터를 읽고 쓸 수 있습니다. 성적 등 민감한 정보는 저장하지 않습니다.
